# 验证与实现边界

## 自动化测试入口

在 Linux / WSL 安装 [04 构建依赖](04-扩展开发与迁移.md)，从项目目录执行。

```bash
python3 EdgeAgent/tests/run_tests.py
```

[run_tests.py](../EdgeAgent/tests/run_tests.py) 依次构建 `EdgeAgent.pro` 和 `TransportTests.pro`，运行组件检查和 MQTT 集成测试。构建日志在 `EdgeAgent/build-proxy/build.log` 和 `EdgeAgent/build-proxy/tests/build.log`。集成测试启动自己的临时 Broker，使用回环端口、伪终端和临时配置，结束后清理测试资源。

## 覆盖范围

| 验证入口 | 覆盖内容 |
| --- | --- |
| [TransportTests.cpp](../EdgeAgent/tests/TransportTests.cpp) | 统一与旧格式编解码、原始正文、HEX 和 1 MiB 上限、字段适用性、CAN 标准帧/扩展帧/RTR 的参数及编解码 |
| 组件测试的分帧和网络检查 | 四种接收分帧、跨读取分隔符、半帧和多帧、大小端长度及帧大小限制。TCP 客户端初次连接失败后重连并完成回环收发 |
| 组件测试的配置检查 | v1/v2、设备绑定、默认 JSON 和显式 legacy、禁用项校验及运行配置过滤。仓库配置默认加载两个通道及绑定。把六个模板全部设为启用后，配置仍可通过解析 |
| [integration.py](../EdgeAgent/tests/integration.py) | 两个代理进程连接临时 Broker，验证 UDP 定向收发及白名单、TCP 服务端分帧及多连接路由、TCP 客户端重连和长度前缀、伪终端串口的空闲分帧及原始下发 |
| 集成测试的拒绝与兼容分支 | 新订阅回放保留命令时拒绝物理发送。统一 TCP 命令拒绝旧连接 ID、歧义目标和端点冲突。禁用通道与启用通道配置同一端口时，测试验证启用端口可用，禁用通道无运行日志和命令回执 |

## 本次执行

2026-11-10 在 WSL Ubuntu 20.04 / Qt 5.12.8 中，以临时目录提供缺失的构建依赖，并用当前源码副本运行仓库测试入口。主程序和组件测试均构建成功，124 项组件检查和 MQTT 集成测试全部通过。

```text
BUILD PASS EdgeAgent.pro
BUILD PASS TransportTests.pro
PASS 124 checks
PASS transparent MQTT integration
ALL TESTS PASSED
```

补充联调使用仓库默认配置跑通了 [04 UDP 示例](04-扩展开发与迁移.md)。实时发布带 RETAIN 的命令时，已有订阅实际执行了 UDP 发送。重启后，同一条命令作为保留消息回放，被代理拒绝。定时退出时，本次 Broker 将连接关闭判定为异常断开，并发布了 `offline` 遗嘱。

TCP 客户端重连后，补充检查确认旧格式命令即使携带旧 `connection_id`，字节也会写入当前连接。独立图形测试工具在同一环境完成了构建和无界面启动检查。

## 验收边界

| 范围 | 当前可确认的行为 |
| --- | --- |
| UDP、TCP | 已覆盖回环单播收发和 TCP 连接生命周期。UDP 组播需在目标网络验证入组和实际来源白名单 |
| 串口 | 伪终端覆盖字节收发与空闲分帧。实际串口参数、USB 拔插与恢复、RS-485 电气和方向切换需现场验收 |
| 经典 CAN | 主程序可构建，组件测试覆盖消息编码、ID、DLC 与 RTR 规则。总线收发、过滤、回环及 Bus-Off 恢复需在对应插件和接口上验收。当前协议仅处理经典 CAN |
| MQTT 状态 | 保留 `online` 由成功连接触发，异常断线依赖 Broker 的 `offline` 遗嘱。退出后的保留状态取决于 Broker 是否收到 MQTT 断开报文。现场通道就绪须结合通道日志与收发验证 |
| 送达与执行 | `sent` 确认本地接口接受发送。消息去重、设备应答及业务执行确认由业务服务处理。代理无持久化补发机制 |
| 运行环境 | 本次覆盖 WSL 中的构建和自动化测试。Windows 原生环境、真实硬件、长时间负载及现场网络需分别验收 |
| 其他功能 | TLS、配置热更新和设备级事务调度尚未实现 |
