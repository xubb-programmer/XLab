# 通信代理：核心实现细节

## 1. 入口与装配

`main.cpp` 初始化日志，依次从 `--config/-c`、`EDGEAGENT_CONFIG`、程序目录 `config.json` 选择配置。配置失败返回退出码 2。`--run-for-ms` 可在指定时间后退出，用于冒烟运行。

项目仅保留一份 config.json。配置加载器校验所有通道和设备绑定后，排除 enabled=false 的通道及其绑定；它们不会占用端口、打开硬件或订阅 MQTT 命令。

`EdgeAgent` 创建各类 Channel，建立设备到通道及通道到设备的映射，再创建 MQTT 客户端。启动时先打开通道，再连接 MQTT；停止时关闭通道并停止 MQTT 网络循环。

## 2. 下行发送

`EdgeAgent::onMqttMessage()` 检查设备和 retained 标记，调用 `decodeSendRequest()` 解析发送请求，再直接调用对应 Channel 的 `send()`。没有设备请求等待队列或活动事务。

`TransportCodec` 完成：

- 1MiB MQTT 正文大小限制。
- TCP/串口原始正文兼容。
- 统一信封的 id/ts/transport/data/meta 校验，以及旧命令别名兼容。
- id 读取或生成 UUID，回执原样关联；HEX 严格校验。
- 统一 meta.endpoint/address/port、connection、frame 的字段及适用性校验。
- TCP 唯一目标匹配、串口/CAN 本地接口约束、CAN 帧 ID/类型/长度校验。

TCP/串口正文若不是 JSON 对象，或者对象不含 data/operation/id/ts/transport/meta 控制字段，按原始字节发送。包含控制字段时按发送信封处理；新旧信封字段混用、未知 metadata 或错误类型均拒绝，不会退化为原始发送。

发送回执仅有 `sent/failed`。`sent` 表示本地发送接口接受字节，不代表对端收到或执行；不自动重试。

## 3. 上行与分帧

UDP 和 CAN 自带报文边界。TCP 和串口使用 `FrameDecoder`：

| 模式 | 缓存及输出 |
|---|---|
| delimiter | 搜索分隔符，输出正文并移除分隔符；支持跨读取分隔符和多帧 |
| fixed_length | 达到指定长度才输出，保留尾部半帧 |
| length_prefix | 读取 1/2/4 字节长度，大端或小端；输出不含长度头 |
| idle_timeout | 持续缓存并重置定时器，静默达到阈值后输出 |

`max_bytes` 限制单帧正文，空闲模式限制缓存总量。TCP 分帧错误会关闭对应连接，串口分帧错误会关闭并安排重开。

TCP 每连接有独立的分帧器和空闲定时器。服务端用 `server-{UUID}`、客户端用 `client-{UUID}` 标识连接，每次接入/重连重新生成，避免旧 connection 指向新会话。统一上行携带 meta.connection 和实际对端 endpoint；下行按两者筛选，未指定且存在多个连接时拒绝。旧信封及原始下行保留原有默认连接选择行为。

`publishTransparent()` 调用 TransportCodec 的 encodeReceivedFrame()，四类通道统一输出 HEX 信封和 meta。encodeSendResult() 产生简洁 id/status 回执及失败 error 对象。message_format=legacy 时使用旧的原始字节/UDP/CAN JSON 和回执结构。

## 4. 连接管理

- UDP：绑定本地地址，按配置加入组播组；来源和目标均检查 allowed_peers。
- TCP Client：连接超时及指数退避重连，成功后重置间隔。
- TCP Server：监听并限制最大客户端数。
- Serial：设置串口参数，严重 I/O 故障后重开，重连间隔指数增长。
- CAN：通过 Qt SerialBus 创建后端，设置过滤器和回环接收；连接/读取错误后重连。经典 CAN 负载最多 8 字节。

SocketCAN 比特率和 Bus-Off 自动恢复需通过外部接口配置，当前代码不使用配置字段自动设置它们。

## 5. 线程、状态及日志

通道和 EdgeAgent 位于 Qt 主事件循环。libmosquitto 使用网络线程，消息正文在回调中复制，经 Qt 信号传回主线程；句柄和订阅列表由互斥锁保护。

MQTT 连接成功后重新订阅，并发布 retained online；异常断开由 Broker 发布 retained offline 遗嘱。正常停止没有主动发布 offline。

日志使用 spdlog，默认写入程序目录 `logs/edgeagent.log`，可通过 `EDGEAGENT_LOG_FILE` 指定。记录通道状态、接收字节和故障；单个日志文件 10MiB，保留 5 个历史文件。
