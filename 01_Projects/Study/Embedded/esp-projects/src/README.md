# 源码目录规范

本目录只放你自己的源码工程。正点原子的官方例程**不移入本目录**,需要时直接从
`D:\XLab\XProjects\esp-projects\doc\1，标准例程-IDF版.zip` 中参考即可。

## 目录结构

```
src/
├── clock/       # 你的工程:网络时钟(小写 + 下划线)
└── ...
```

## 命名规则

1. 项目文件夹:全小写字母 + 下划线,例如 `blink_led`、`oled_demo`
2. 源码文件:全小写字母 + 下划线,`.c` 与 `.h` 同名配对,例如 `oled_driver.c` / `oled_driver.h`
3. 工程入口统一叫 `main.c`,放在每个工程的 `main/` 目录下

## 代码风格

1. 宏定义、常量:全大写 + 下划线,例如 `WIFI_SSID`
2. 函数、变量:小写驼峰,例如 `lcd_draw_clock()`、`time_buf`
3. 每个源文件顶部写明文件作用,关键代码行必须加详细中文注释
4. 每个函数前用注释说明:函数功能、参数、返回值
